# Лабораторная работа: Конвертер секунд

## 1. Словесный алгоритм
1. Начало.
2. Ввод строки пользователем.
3. Если ввод не число или число меньше 0, вывести "Ошибка: Некорректный ввод" и завершить.
4. Вычислить часы: hours = секунды / 3600.
5. Вычислить минуты: minutes = (секунды % 3600) / 60.
6. Вычислить остаток секунд: seconds = секунды % 60.
7. Вывести часы, минуты и секунды на экран.
8. Конец.

## 2. Псевдокод
Алгоритм Перевод_Секунд
Начало
    Вывод("Введите количество секунд:")
    Ввод(inputStr)
    Если (Не Число(inputStr)) ИЛИ (Число(inputStr) < 0) То
        Вывод("Ошибка: Некорректный ввод")
    Иначе
        sec = КонвертироватьВЦелое(inputStr)
        hours = sec / 3600
        minutes = (sec % 3600) / 60
        seconds = sec % 60
        Вывод(hours, " ч ", minutes, " мин ", seconds, " с")
    Конец_Если
Конец
