# Трассировка алгоритмов

Исходный массив: a = {4, 1, 7, 3, 9}, размер n = 5.

## 1. Циклический сдвиг влево на одну позицию
Буфер (temp) = a[0] = 4.

| Шаг | i | Состояние массива после шага | Пояснение |
|-----|---|------------------------------|-----------|
| Исходное | - | {4, 1, 7, 3, 9} | Начальное состояние |
| 1 | 0 | {1, 1, 7, 3, 9} | a[0] = a[1] |
| 2 | 1 | {1, 7, 7, 3, 9} | a[1] = a[2] |
| 3 | 2 | {1, 7, 3, 3, 9} | a[2] = a[3] |
| 4 | 3 | {1, 7, 3, 9, 9} | a[3] = a[4] |
| 5 | - | {1, 7, 3, 9, 4} | В конец (a[4]) пишем буфер |

Результат сдвига: {1, 7, 3, 9, 4}

---

## 2. Разворот массива на месте
Исходный массив: a = {4, 1, 7, 3, 9}, размер n = 5. Цикл идет до n / 2 = 5 / 2 = 2 (индексы i = 0 и i = 1).

| Шаг | i | Обмен элементов | Состояние массива после шага |
|-----|---|-----------------|------------------------------|
| Исходное | - | - | {4, 1, 7, 3, 9} |
| 1 | 0 | Обмен a[0] и a[4] (4 и 9) | {9, 1, 7, 3, 4} |
| 2 | 1 | Обмен a[1] и a[3] (1 и 3) | {9, 3, 7, 1, 4} |

* **Количество обменов:** Выполнено 2 обмена.
* **Почему цикл идёт только до n / 2:** Если цикл пойдет дальше середины массива, он начнет менять местами уже перевернутые элементы обратно. В итоге массив вернется в свое первоначальное состояние.

## 3. Алгоритм поиска минимума с min = 0
* **Массив, на котором алгоритм ошибается:** {4, 1, 7, 3, 9} (или любой массив, где все числа строго больше нуля, например {5, 8, 3}). 
* **В чем ошибка:** Алгоритм считает, что начальный минимум равен `0`. Но нуля в самом массиве вообще нет. В итоге программа выдаст ответ, что минимум равен `0`, хотя реальный минимум — это `1`.
* **Исправление:** Начальное значение нужно брать из самого массива (первый элемент), то есть исправить на: `min = a[0]`.
