## 1. Ручная трассировка s.Trim() и Split(';')
Исходная строка: s = " Ахметов Ерлан;85 "

Сначала s.Trim() убирает пробелы в начале и в конце. Получается строка: "Ахметов Ерлан;85"
Потом Split(';') делит её по точке с запятой на два элемента.

Результаты элементов массива:
* Индекс: "Ахметов Ерлан" (длина = 13 символов, так как 7 букв фамилии + пробел + 5 букв имени)
* Индекс: "85" (длина = 2 символа)

## 2. Трассировка int.TryParse для line = "Иванов Пётр;70;85;x"
После сплита по ';' получаем 4 части. Проверяем TryParse для каждой:

* Индекс 0: Часть = "Иванов Пётр" -> TryParse вернет false, в out запишет 0 (потому что это текст).
* Индекс 1: Часть = "70" -> TryParse вернет true, в out запишет 70.
* Индекс 2: Часть = "85" -> TryParse вернет true, в out запишет 85.
* Индекс 3: Часть = "x" -> TryParse вернет false, в out запишет 0 (это буква, а не число).

Что вернет метод TryParseScores:
Метод вернет false. Потому что в строке есть элементы ("Иванов Пётр" и "x"), которые невозможно сконвертировать в числа. Из-за этих ошибок весь парсинг строки завалится.

## 3. Сколько объектов string создается (s += i vs StringBuilder)
В C# строки неизменяемые. Каждое изменение — это создание новой строки в памяти.

Цикл for (i = 0; i < 4; i++):

При s += i (на каждом шаге):
* Шаг 0 (i=0): создается строка "0" из переменной i, и новая строка "0" как результат сложения. (2 объекта)
* Шаг 1 (i=1): создается строка "1" из i, и новая строка "01" от сложения. (2 объекта)
* Шаг 2 (i=2): создается строка "2" из i, и новая строка "012" от сложения. (2 объекта)
* Шаг 3 (i=3): создается строка "3" из i, и новая строка "0123" от сложения. (2 объекта)
Итого в цикле создается 8 новых строковых объектов.

При sb.Append(i) в StringBuilder:
В самом цикле создается 0 объектов string. StringBuilder работает внутри своего динамического буфера (массива символов) и просто дописывает туда данные без создания лишних объектов в памяти. Строка создастся всего 1 раз, когда в конце мы вызовем sb.ToString().

## 4. Почему s не изменилась после s.ToUpper() без присваивания
Так как строки в C# неизменяемые (immutable), метод s.ToUpper() не может изменить саму переменную s. 

Этот метод берет значение s, делает копию в верхнем регистре и возвращает её как совершенно новую строку. Но в коде этот результат никуда не присваивается. Новая строка просто создалась и сразу потерялась в памяти, а старая s осталась прежней. 

Чтобы сработало, надо писать с присваиванием: s = s.ToUpper();
