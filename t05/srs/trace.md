# Трассировка рекурсии

Дана функция:
`static int F(int n) { if (n <= 1) return 1; return n * F(n - 1); }`

## 1. Базовый случай и шаг рекурсии
* **Базовый случай:** Условие `if (n <= 1) return 1;`. Это точка остановки рекурсии. Когда `n` становится меньше или равно 1, функция перестает вызывать саму себя и просто возвращает единицу.
* **Шаг рекурсии:** Строка `return n * F(n - 1);`. Это этап, на котором функция вызывает саму себя с уменьшенным аргументом `(n - 1)`.

---

## 2. Ручная трассировка F(4)

Таблица вызовов вниз по стеку и возвращаемых значений вверх:

| Вызов | Глубина | Возвращает | Пояснение |
|-------|---------|------------|-----------|
| F(4)  | 1       | 24         | Ждет результат F(3), считает: 4 * 6 = 24 |
| F(3)  | 2       | 6          | Ждет результат F(2), считает: 3 * 2 = 6  |
| F(2)  | 3       | 2          | Ждет результат F(1), считает: 2 * 1 = 2  |
| F(1)  | 4       | 1          | Сработал базовый случай (n <= 1), возвращает 1 |

Итоговый результат выполнения `F(4) = 24`.

---

## 3. Анализ вызова F(-1) при изменении условия на n == 1
* **Что произойдет:** Программа уйдет в бесконечную рекурсию и аварийно завершится.
* **Почему это произойдет:** При вызове `F(-1)` условие остановки `n == 1` не сработает (так как -1 не равно 1). Функция выполнит шаг рекурсии и вызовет `F(-2)`, затем `F(-3)`, `F(-4)` и так далее до бесконечности в сторону уменьшения. Число `n` никогда не станет равным 1.
* **К какой ошибке это приведет:** Программа исчерпает всю выделенную память под вызовы функций и упадет с критической ошибкой **`StackOverflowException`** (переполнение стека).
